Artifact: Security Threat Monitoring Dashboard

The Security Threat Monitoring Dashboard is a full-stack security-focused application built with JavaScript, Node.js, Express, MongoDB Atlas, Mongoose, JWT authentication, HTML, and CSS. The project simulates a simplified SIEM-style workflow by allowing users to authenticate, create security logs, generate alerts, calculate threat scores, rank suspicious IP addresses, and view database analytics.

Enhancement One: Software Design and Engineering

The software engineering enhancement expanded the artifact from a backend-only API into a more complete full-stack application. I added a frontend dashboard, input validation, improved error handling, and better documentation.

Enhancement Two: Algorithms and Data Structures

The algorithms enhancement added weighted threat scoring, suspicious IP ranking, and alert prioritization. These features allow the system to evaluate events dynamically instead of relying only on fixed severity rules.

Enhancement Three: Databases

The database enhancement added MongoDB indexes, aggregation queries, analytics summaries, severity breakdowns, and event statistics. These changes improved how the application stores, retrieves, and summarizes security data.
