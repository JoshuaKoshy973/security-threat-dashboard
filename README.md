# Security Threat Monitoring Dashboard

## Overview

This project is a full-stack Security Threat Monitoring Dashboard developed as part of the CS-499 Computer Science Capstone. The application demonstrates software engineering, algorithms and data structures, and database concepts through a security-focused dashboard.

## Technologies

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- HTML
- CSS
- JavaScript

## Software Engineering Enhancements

- Modular project architecture
- Improved frontend dashboard
- Input validation
- Better error handling
- Documentation updates

## Algorithms and Data Structures Enhancements

- Weighted threat scoring
- Suspicious IP ranking
- Event prioritization
- Threat score calculations

## Database Enhancements

- MongoDB aggregation pipelines
- Database analytics summary
- Top suspicious IP analysis
- Indexed log collections
- Optimized schema design
- Dashboard analytics queries

## Features

- User authentication
- Security log creation
- Automatic alert generation
- Threat scoring
- Recent alerts
- Suspicious IP rankings
- Database analytics dashboard
